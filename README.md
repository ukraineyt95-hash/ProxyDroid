# ProxyDroid

Android VPN-приложение с встроенным `socks5_proxy.py`: приложение запрашивает системное VPN-разрешение, создаёт TUN-интерфейс, запускает Python-прокси внутри процесса и перенаправляет через него IPv4/IPv6-трафик устройства.

## Что реализовано

- Главный экран «Подключить / Отключить», статус VPN и отдельный экран настроек.
- `VpnService`: TUN создаётся через `VpnService.Builder.establish()` **до запуска обработчика трафика**. Маршрутизируются IPv4 и IPv6; собственный процесс ProxyDroid исключён из VPN, чтобы сокеты прокси не попадали обратно в свой же TUN.
- Исходный прокси из вложения находится в `app/src/main/python/socks5_proxy.py` и исполняется через Chaquopy. `android_runner.py` связывает дескриптор Android TUN с Python-движком `Tun2Socks`.
- DNS-пакеты из TUN перенаправляются во встроенный DNS-сервер с Fake-IP; используются upstream и диапазон из настроек.
- Для локального SOCKS5 при первом запуске генерируются логин и пароль; оба набора учётных данных (локальный и внешний) хранятся в зашифрованном виде с помощью Android Keystore.
- Настройки включают все аргументы командной строки исходного скрипта:

  | Флаг скрипта | Поле в приложении |
  | --- | --- |
  | `--host` | адрес прослушивания (безопасное значение по умолчанию: `127.0.0.1`) |
  | `--port` | порт SOCKS5/PAC/mKCP |
  | `--username` | логин локального SOCKS5 |
  | `--password` | пароль локального SOCKS5 |
  | `--print-cert` | переключатель вывода TLS-сертификата mKCP/H2Mux |
  | `--dns-host` | адрес привязки DNS-сервера |
  | `--dns-port` | UDP-порт DNS-сервера |
  | `--dns-upstream` | DNS upstream в формате `host:port` |
  | `--fake-ip-range` | Fake-IP сеть IPv4 CIDR |

- Дополнительно есть необязательный внешний SOCKS5 для маршрута TUN. Если поле пустое, TUN использует встроенный прокси. Если задано — локальный сервер продолжает работать, а трафик устройства направляется через внешний SOCKS5. Логин и пароль upstream задаются отдельно от адреса и также хранятся зашифрованно.
- В настройках есть переключатель **UDP-over-TCP**. Для него реализовано парное расширение SOCKS5: команда `0x80`, далее кадры `4-byte length + SOCKS address + UDP payload`. Это не стандарт SOCKS5; удалённый upstream должен поддерживать то же расширение. Встроенный сервер ProxyDroid его поддерживает. Обычный SOCKS5 UDP ASSOCIATE остаётся режимом по умолчанию.

## Безопасность и границы

- Локальный слушатель по умолчанию привязан к `127.0.0.1`; при первой установке включена SOCKS5-авторизация с автоматически сгенерированным паролем. Даже loopback-порт потенциально могут использовать другие приложения Android. Если изменить `--host` на `0.0.0.0` или адрес сетевого интерфейса, оставьте авторизацию включённой: иначе прокси будет доступен другим устройствам в сети. Приложение предупреждает об открытом профиле.
- Если внешний SOCKS5 не задан, встроенный сервер устанавливает TCP/UDP-соединения напрямую к адресатам. Это не удалённый VPN, не географическая смена IP и не шифрование трафика до доверенного сервера.
- DNS upstream из `--dns-upstream` — отдельный DNS-сервер; встроенный резолвер отправляет ему запросы напрямую. Он не проксируется через внешний SOCKS5.
- UDP-over-TCP переносит UDP-пакеты от TUN-клиента к совместимому SOCKS5-серверу по TCP; сам сервер затем отправляет UDP-пакеты адресатам. Этот режим не делает произвольный SOCKS5-сервер совместимым.
- Android показывает системное VPN-подтверждение и постоянное уведомление, пока туннель активен.

## Сборка

Нужны Android Studio или Android SDK Platform 35, JDK 17 и Gradle Wrapper. В корне проекта:

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Проект рассчитан на Android 8.0 (API 26) и новее; Chaquopy упаковывает Python 3.11 для `arm64-v8a`, `armeabi-v7a`, `x86_64` и `x86`.

## Проверки Python-части

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile app/src/main/python/*.py
```

Проверяются UDP-over-TCP SOCKS-расширение, его использование TUN-движком, локальная переадресация DNS-пакетов и запуск/остановка runner с тестовым TUN-дескриптором.
